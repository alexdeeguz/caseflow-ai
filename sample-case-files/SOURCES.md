# Document design references

These public blank forms and public sample records were consulted for document
structure and common information fields. All case narratives, medical entries,
names, dates, observations and amounts in this pack are newly invented. No real
patient record, issuer logo, seal or signature was reproduced.

- [Los Angeles accident / incident forms](https://personnel.lacity.gov/documents/form5020.pdf): reference for compact labeled fields, event descriptions and witness limitations.
- [Oregon Tech witness form](https://www.oit.edu/sites/default/files/document/witness-incident-form.pdf): reference for separating the witness position, direct observations and follow-up comments.
- [OccuPro sample progress / re-evaluation record](https://www.occupro.net/docs/default-source/request-documents/sample-reports/patient-progress-note-re-evaluation.pdf): reference for clinical demographics, functional history and comparison tables.
- [Virginia Victims Fund public itemized-bill example](https://vvf.virginia.gov/sentara-health-itemized-bill-sample): reference for dated charges, credits and account balance as separate quantities.

Original layouts were created for this pack. Similarity of general form fields
does not indicate affiliation with the reference issuers. The PDFs intentionally
use varied typefaces, dense prose, tables, headers and page numbers rather than
application branding. Small fictional-data footers identify every page.
